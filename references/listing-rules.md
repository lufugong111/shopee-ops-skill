# Listing Rule Groups

Explain the relevant groups before asking the user to choose. Mandatory platform, legal, API, and category constraints always apply. The examples below are choices to ask about, not defaults to impose.

## Required Context

Confirm or infer for confirmation:

- Shopee marketplace/country, shop, currency, category, and desired language.
- Operation: create a draft, publish a new item, publish an existing draft, or update an existing item.
- Product source (user files, connected catalog/Bitable, or other approved source) and exact record/item IDs.
- Whether confirmed rules should apply only once or be proposed as reusable shop defaults.

## Optional Rule Groups

Ask which groups apply to this listing:

- Content: title pattern, language, tone, description sections, banned terms, claims and evidence requirements.
- Price and inventory: currency, current/original price, minimum margin, stock source, safety stock, and promotion eligibility.
- SKU and variations: SKU syntax, option order/names, size/color translations, variation image mapping, and combination handling.
- Media: image ordering/count, background requirements, video requirements, watermark/brand rules, and allowed source assets.
- Logistics and service: shipping channel/fee, free shipping, package weight/dimensions, delivery promises, returns, and warranty wording.
- Attributes and compliance: category attributes, certifications, material/origin evidence, restricted goods, and marketplace-specific disclosure.
- Campaign and launch: bundle/discount rules, campaign dates, vouchers, stock allocation, and whether public activation is allowed.
- Existing-item update scope: exact fields that may change and fields that must remain untouched.

## Confirmation Summary

Before any live mutation, summarize in plain language:

- Marketplace, shop, item or source-record scope.
- Create/update/publish action and resulting status.
- Effective mandatory and user-selected rule groups.
- Title, category, price, stock, variations, media, shipping, and attributes that will be submitted.
- Any unresolved assumptions or policy limitations.

Ask the user to explicitly confirm this exact action. If they edit a material field after confirmation, show the revised summary and confirm again. Never treat a prior general instruction such as "上架这些商品" as authorization to publish publicly.
